# ADC0808 定时采样显示

8253 两级分频产生 10 Hz 中断请求，8259 响应后在中断服务程序中启动 ADC0808 采样，结果的高 4 位经 8255 送到七段数码管显示。

## 文件

| 文件 | 行数 | 说明 |
|---|---|---|
| `adc0808_original.asm` | 217 | 初版，初始化与中断逻辑全部内联 |
| `adc0808_refactored.asm` | 318 | 重构版，子程序化 + `EQU` 常量端口 |
| `proteus/adc0808_demo.pdsprj` | — | Proteus 8 仿真工程 |

两个文件功能等价，重构版是重写后的形态，差异对比见[仓库根 README](../README.md#初版与重构版)。

## 信号链

```
1 MHz ─┬─ 8253 C0 方式3 初值1000 ─ 1 kHz ─┬─ 8253 C1 方式2 初值100 ─ 10 Hz
       │                                  │
       └──────────────────────────────────┴─→ 8259 IR0（类型 60H）
                                                    │
                                          ISR: 启动ADC → 延时 → 读值
                                                    │
                                    取高4位 → 查段码表 → 8255 PB → 数码管
```

单级分频做不到 10 Hz：8253 计数器最大 65536，1 MHz 输入下最慢约 15 Hz，所以拆成 1000 × 100 两级。

## 端口

| 芯片 | 端口 |
|---|---|
| 8253 C0 / C1 / 控制口 | `200H` / `202H` / `206H` |
| 8259 命令口 / 数据口 | `300H` / `302H` |
| 8255 PB / 控制口 | `102H` / `106H` |
| ADC0808 | `400H` |

## 重构版做了什么

`IRQ_HANDLER` 只保留流程编排：

```asm
CALL TRIGGER_ADC        ; 启动转换
CALL WAIT_ADC_DONE      ; 等待完成
CALL PROCESS_ADC_DATA   ; 读数 + 查表 + 输出
CALL SEND_EOI_TO_PIC    ; 发 EOI
```

具体实现下沉到各子程序。初版把这一整套内联在 `INT_PROC` 里，要读完全程才知道主线是什么。

## 已知限制

- `WAIT_ADC_DONE` 是固定次数的 `LOOP` 盲延时，未查询 EOC 引脚。ADC0808 转换时间随时钟变化，时钟变慢时会读到无效值。
- ADC0808 的 START 与 OE 在仿真中合用同一端口地址，靠读写方向区分；真实电路上这是两个独立控制信号。
- 中断内各子程序自带 `PUSH`/`POP`，与 `IRQ_HANDLER` 的现场保护重复，属冗余但无害。
