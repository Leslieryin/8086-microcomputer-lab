# 抢答计时器

8255 + 8254 实现的智力竞赛抢答计时器，20 秒倒计时、双人抢答、动态扫描数码管显示。

## 文件

| 文件 | 说明 |
|---|---|
| `buzzer_timer.asm` | 完整实现，343 行，MASM/TASM 语法 |

## 硬件配置

| 芯片 | 端口 | 用途 |
|---|---|---|
| 8255 PA | `298H` | 数码管段码 |
| 8255 PB | `299H` | PB0/PB1 位选，PB7 蜂鸣器 |
| 8255 PC | `29AH` | PC0 启动键，PC1/PC2 抢答键（低电平有效） |
| 8255 控制口 | `29BH` | 方式 0，`81H` |
| 8254 通道 0 | `280H` | 定时基准，方式 0 |
| 8254 控制口 | `283H` | — |

## 逻辑要点

- 三个标志位 `RUN_FLAG` / `LOCK_FLAG` / `WINNER` 构成全部状态
- 抢答键检测先验 `RUN_FLAG=1` 且 `LOCK_FLAG=0`，从而实现"开抢前无效"与"抢答后锁定"
- `AAM` 指令把 `CUR_TIME` 拆成十位（AH）和个位（AL）
- 动态扫描时位选用 `AND AL,0FCH` 只清低两位，保住 PB7 的蜂鸣器电平
- 倒计时归零后进入 `HOLD_RESULT` 持续刷新，结果定格

端口地址按实验箱定义，换硬件平台时改 `EQU` 段即可。
